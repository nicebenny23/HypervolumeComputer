# Convex Hypervolume Computer

A C++ program for computing the hypervolume of convex geometric objects in arbitrary dimensions.

## Overview

This project explores computational geometry and algorithms for calculating the volume/hypervolume of convex shapes from their geometric representation.
## What It Does

Given a convex geometric object, the program:
Converts it into a polyhedral mesh with both vertices and facets using the beneath beyond algorithm.
Computes the average radius of the shape, converting this into a volume metric.
